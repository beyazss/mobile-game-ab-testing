# Data

`cookie_cats.csv` contains anonymized player-level data from the publicly shared Cookie Cats A/B test.

Source used for this project: [public GitHub mirror — Mobile Games A/B Testing with Cookie Cats](https://github.com/ryanschaub/Mobile-Games-A-B-Testing-with-Cookie-Cats)

The dataset is included so the analysis can be reproduced without an additional download step.
